## ✨ 核心特性

- **定时任务**: 基于固定时间配置的任务，支持按年/月/周/日/时/分重复执行
- **节假日跳过**: 支持配置节假日跳过策略
- **灵活调度**: 支持开始/结束时间、重复周期等配置

## 🆚 社区版 vs 商业版

| 功能模块 | 具体能力 | 🟢 社区版 | 🔵 商业版 |
| :--- | :--- | :---: | :---: |
| **定时任务** | 基于固定时间配置的任务 | ✅ | ✅ |
| **日期字段任务** | 基于数据模型日期字段触发的任务 | ❌ | ✅ |
